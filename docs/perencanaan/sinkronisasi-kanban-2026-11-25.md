# Sinkronisasi kartu sprint dengan revisi proposal

Dokumen ini menyiapkan uraian kartu yang mengikuti berkas revisi. Paket ZIP tidak mengubah issue atau project board GitHub. Terapkan perubahan berikut pada kartu terkait saat pembaruan sprint dilakukan, dengan mempertahankan status aktual, komentar, dan bukti yang sudah ada.

| Kartu/tugas | Uraian yang digunakan |
|---|---|
| S01 W01-T01–T03 | Acuan FINAL INI A(2).docx dan acuan-revisi.md; kelompok berasal dari frame sekitar lima detik sebelum hijau; jumlah kelompok sama dengan manual_total pada anotasi sah |
| S01 W02-T02 dan W02-T05 | Alur AI/pencatatan memakai identitas dan waktu snapshot; pengamatan manual mengikuti kelompok yang sama dari frame sebelum hijau |
| S01 W03-T01 | GPIO sesuai proposal: A 25/26/27, B 14/18/19, C 23/32/33, OLED SDA21/SCL22; skema dan contoh pin map versi revisi |
| S01 W03-T04–T06 | Prosedur, kamus CSV, dan UJI-32 memeriksa kelompok dari frame terpilih, keanggotaan tetap, serta layanan mulai saat hijau |
| S01 W03-T07 | Tinjau paket konsistensi dan hasil pemeriksaan berkas; penerimaan PM tetap dicatat setelah review aktual |
| S02 W04-T01 dan W04-T04 | Gunakan .env.example dan panduan infra/lingkungan-server.md; isi konfigurasi lokal dan bukti pemeriksaan aktual |
| S02 W04-T03–T06 | Lengkapi inventaris fisik, rekap kesiapan dan review; paket dokumentasi tidak menggantikan pemeriksaan komponen |
| S03 W05-T01–T05 | Ikuti mulai-sprint-03.md dan GPIO revisi; kumpulkan firmware serta bukti rangkaian/ukuran aktual |
| S04 W08-T02 | Tandai kelompok pada frame kepadatan sekitar lima detik sebelum hijau. Pertahankan anggota, mulai mengukur saat hijau, ikuti lintas hijau jika terlacak dan jumlahkan hijau saja |
| S06 UJI-32 | Uji bahwa kendaraan yang masuk setelah snapshot tidak ditambahkan dan initial_queue_count sama dengan manual_total pada anotasi sah |

ID tugas, PIC, dan susunan minggu S01–S08 tetap mengikuti pembagian-kerja.md. Pembaruan uraian tidak mengubah status kartu menjadi selesai dan tidak mengisi hasil uji yang belum dijalankan.
